# Change Log

All notable changes to the "Windsurfer" extension will be documented in this file.

## [0.0.13] - 2025-05-03

### Added
- Implemented direct message sending to Windsurf chat
- Added support for insertText API endpoint
- Added documentation for new message sending functionality

### Changed
- Refactored the extension into a modular architecture
- Improved error handling and resource management
- Updated documentation with new features and API endpoints

### Fixed
- Fixed issues with button management
- Improved WebSocket server stability
